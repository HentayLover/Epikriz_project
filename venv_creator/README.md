# Автоматическое создание venv

Тут расположенно два файла:

- *venv.bat* , который создаёт вирутальное окржуение и устанавливает все библиотеки из файла requirements.txt

- *project.bat*, который создаёт виртуальное окржуение и файл нужного для данного проекта типа и все библиотеки из requirements.txt
